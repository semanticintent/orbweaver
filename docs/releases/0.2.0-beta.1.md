# Orbweaver 0.2.0-beta.1

`0.2.0-beta.1` is the first adoption-oriented release of Orbweaver's v0.2
semantic visualization platform.

## Highlights

- Versioned, coordinate-free semantic graph and proposal contracts.
- Deterministic layout and accessible SVG, with semantic inspection,
  keyboard/pointer interaction, zoom, pan, focus, and progressive disclosure.
- Reviewable annotations, semantic lenses, focused-path narratives, generated
  legends, and architecture comparison.
- Supported SVG, PNG, and self-contained interactive HTML artifacts.
- Compatibility documents, browser/accessibility coverage, visual regression,
  and performance budgets.
- A provider-neutral AI proposal boundary: models may propose meaning; the
  package validates and renders deterministically.

## Stability statement

The public Graph, proposal-validation, rendering, interaction, viewport,
export, and semantic-intelligence APIs are treated as stable for normal beta
adoption. Before `1.0`, a breaking change is reserved for a material defect,
security issue, ambiguity, or demonstrated integration failure, with a
migration note and compatibility fixture where practical.

## Intentionally outside the package

The public website may provide experimental WebMCP and optional model-assisted
proposal experiences. They remain host-owned, provider-specific, and subject to
explicit human acceptance. `@semanticintent/orbweaver` itself contains no AI
SDK, credential, network call, model provider, or authored geometry.

## Verification

- 134 unit tests
- 12 cross-browser interaction/accessibility checks across Chromium, Firefox,
  and WebKit
- Bundle and performance budgets across representative semantic graph sizes
- Versioned artifact and compatibility fixtures

See [v0.2 beta readiness](../v0.2-beta-readiness.md) for the release evidence
and compatibility policy.
